# Licensing

Verilog Academy ships under more than one licence, because it contains more
than one kind of material. This page explains which licence covers which part
of the repository. The licence texts themselves are in the files named below.

## Quick summary

| Material | Licence | File |
|---|---|---|
| Website source code and original Verilog examples | MIT | [`LICENSE`](LICENSE) |
| Original educational prose, diagrams and explanatory content | CC BY-NC-SA 4.0 | [`LICENSE-CONTENT`](LICENSE-CONTENT) |
| Bundled third-party fonts | SIL Open Font License 1.1 | [`assets/fonts/OFL-1.1.txt`](assets/fonts/OFL-1.1.txt) |
| Third-party tools, notices and attribution | As stated per item | [`THIRD-PARTY-NOTICES.md`](THIRD-PARTY-NOTICES.md) |

## MIT — source code and Verilog examples

The MIT licence in [`LICENSE`](LICENSE) applies to the original code in this
repository. That means:

- HTML templates and generated page markup;
- CSS in `css/`;
- JavaScript in `js/`;
- the Python build, preview and verification scripts in `tools/`;
- the original Verilog designs, testbenches and expected transcripts in
  `examples/verilog`, `examples/labs` and `examples/playground`.

You may use, copy, modify, merge, publish, distribute, sublicense and sell
this code, provided the copyright notice and permission notice are retained.

## CC BY-NC-SA 4.0 — educational content

The licence in [`LICENSE-CONTENT`](LICENSE-CONTENT) applies to the original
teaching material written for this project. That means:

- lesson prose and explanations;
- the wording of laboratory procedures;
- quiz questions, answer options and explanations;
- original diagrams, tables and figures;
- the setup and usage guides.

This content is licensed for non-commercial reuse with attribution, and
adaptations must be shared under the same licence.

## SIL OFL 1.1 — bundled fonts

The nine WOFF2 font files in `assets/fonts/` are third-party works redistributed
under the SIL Open Font License 1.1. They are **not** covered by the MIT or
CC BY-NC-SA licences above.

- Full licence text and the copyright notices for Space Grotesk, Inter and
  JetBrains Mono: [`assets/fonts/OFL-1.1.txt`](assets/fonts/OFL-1.1.txt)
- Per-file family, weight, style, version and source metadata:
  [`assets/fonts/README.md`](assets/fonts/README.md)

## Third-party material and tools

[`THIRD-PARTY-NOTICES.md`](THIRD-PARTY-NOTICES.md) records the third-party
material included in or used to build this project, with its own attribution
and licence terms. Where this project and a third-party notice disagree about
third-party material, the third-party notice governs.

Nothing in this repository relicenses third-party material under MIT or
CC BY-NC-SA 4.0, and no ownership is claimed over it.

does not certify that every use is cleared. If you intend to reuse this
material commercially, in a course, or in a product, check the applicable
licence text yourself and take advice where it matters.
