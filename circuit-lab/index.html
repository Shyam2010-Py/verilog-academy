01 / The workbench

Set. Read. Prove.

Every demo runs the same loop. Set the active-high inputs, read the live outputs and diagram, then open the notes and compare the highlighted row with the Boolean equation.

01

Set the inputs

Each switch is a logic source. A switch labelled 1 drives the node high; 0 drives it low. Buses such as A3…A0 are grouped, with the highest bit first.

02

Read the outputs

LEDs and numeric values show the present output. The SVG diagram colours live wires and highlights the selected channel or active path. The Boolean expression never changes; the values do.

03

Check the table

Open the notes to load the complete truth table. The row matching the live inputs is highlighted. For the flip-flop, the state table and edge log replace combinational highlighting.

Conventions used here

Active-high, ideal timing, honest boundaries.

Active-high
A plain signal name means 1 = high = true. A bubble, overbar or “active-low” label marks the opposite polarity. Q̄ is the complement of Q.
Combinational
No stored state. Outputs settle from the present inputs. Real gates add propagation delay; this model updates immediately.
Sequential
State changes only on a clock edge, except asynchronous reset. The D flip-flop exposes clock, enable and reset separately so you can test each one.
Not Verilog
The engine evaluates JavaScript logic functions. It does not parse, compile or simulate Verilog, and it is not a timing-accurate simulator.

AND Gate

The AND gate produces 1 only when every input is 1. With two inputs there is exactly one true row in its truth table.

2 inputs · 1 output · 4 combinations
logic 1 logic 0 active-high
Inputs
Outputs
Y0

Set the inputs to evaluate this circuit.

Boolean Y = A · B
Study this circuit 2 inputs · 1 output · 4 combinations · truth table and worked notes

Learning objectives

  • Relate the AND symbol to the Boolean product Y = A · B.
  • Predict the output for all four input pairs before switching.
  • Recognise that a single 0 input forces the output to 0.

Circuit operation

Each input is a logic level. The output is the logical product of A and B, so it is high only when both switches are high. Any low input blocks the output.

In gate-level Verilog this behaviour is `and (y, a, b)`; in dataflow it is `assign y = a & b;`. The interactive diagram evaluates the same equation in JavaScript.

Inputs and outputs

A and B are active-high inputs: logic 1 means the switch is on and the node is high. Y is the active-high output. A dot in the Boolean equation means logical AND, not arithmetic multiplication.

Practical example

  • Enabling a signal only when a device is selected and its data is valid.
  • Building the carry term of an adder and the enable path of a register.

Observations

  • AND is not the same as OR: three of the four rows produce 0.
  • The output is 0 for 0·1, 1·0 and 0·0. Only 1·1 produces 1.

Common mistakes

  • Reading the symbol as OR because both inputs enter the flat side.
  • Assuming an unconnected input is high; an undriven input is unknown, not 1.

Learning objectives

  • Relate the OR symbol to the Boolean sum Y = A + B.
  • Identify the single row that produces 0.
  • Distinguish logical OR from arithmetic addition.

Circuit operation

The output is the logical sum of A and B. If either switch is high the output is high; only 0 and 0 leave it low.

Verilog writes this as `assign y = a | b;`. The plus sign in Boolean algebra means OR, not binary addition, so 1 + 1 still produces 1.

Inputs and outputs

A and B are active-high inputs. Y is high when either input is high, and low only for A = 0 and B = 0. The plus sign in the equation means logical OR, so 1 + 1 still gives 1, with no carry.

Practical example

  • Combining multiple interrupt requests into one alert signal.
  • Detecting that any one of several fault conditions is active.

Observations

  • Three of the four rows produce 1, the mirror image of AND.
  • Boolean 1 + 1 = 1; arithmetic 1 + 1 = 10 is a different operation.

Common mistakes

  • Expecting OR to carry like a binary adder.
  • Confusing the curved input side of OR with the flat input side of AND.

The inverter produces the complement of its single input. It is the only one-input gate in the set.

logic 1 logic 0 active-high
Inputs
Outputs
Y1

Set the inputs to evaluate this circuit.

Boolean Y = ~A
Study this circuit 1 input · 1 output · 2 combinations · truth table and worked notes

Learning objectives

  • Relate the triangle-and-bubble symbol to logical inversion.
  • Explain why the inverter has no two-input truth table.
  • Use inversion to form active-low signals.

Circuit operation

The output is the opposite of the input. A 0 becomes 1 and a 1 becomes 0, with no other possible result for a defined input.

Verilog writes the complement as `~a`. In gate-level form the primitive is `not (y, a)`. Inversion is the basis of NAND, NOR, XNOR and active-low control.

Inputs and outputs

A is the single active-high input and Y is its complement. When A is high, Y is low; when A is low, Y is high. The small circle at the gate output is the inversion bubble.

Practical example

  • Generating the select complement inside a 2:1 multiplexer.
  • Converting an active-high request into an active-low enable.

Observations

  • The bubble at the output means inversion, not a separate gate.
  • An inverter cannot create a defined output from an unknown input; the result is unknown.

Common mistakes

  • Drawing the bubble on the input side and calling it an inverter.
  • Forgetting that two inverters in series restore the original polarity.

NAND Gate

NAND is an AND gate followed by an inverter. It is low only when both inputs are high.

2 inputs · 1 output · 4 combinations
logic 1 logic 0 active-high
Inputs
Outputs
Y1

Set the inputs to evaluate this circuit.

Boolean Y = ~(A · B)
Study this circuit 2 inputs · 1 output · 4 combinations · truth table and worked notes

Learning objectives

  • Read NAND as inverted AND.
  • Identify the only input pair that produces 0.
  • Explain why NAND is called a universal gate.

Circuit operation

The gate forms A · B and then complements the result. The output is 0 only for A = 1 and B = 1; every other row is 1.

Verilog dataflow uses `assign y = ~(a & b);` or the primitive `nand (y, a, b)`. NAND can implement NOT, AND, OR and any other combinational function when gates are combined.

Inputs and outputs

A and B are active-high inputs and Y is the active-high output. NAND is an AND gate with an output bubble, so the output is the complement of A · B. The bubble marks the inversion, not an active-low input.

Practical example

  • Building flash memory and SR latch structures from cross-coupled NAND gates.
  • Implementing arbitrary logic in a NAND-only ASIC library.

Observations

  • NAND is the complement of AND, so every row is reversed.
  • The output is 1 for three of the four input pairs.

Common mistakes

  • Placing the bubble on the inputs instead of the output; that describes an OR gate with inverted inputs.
  • Forgetting the inversion when converting an AND design to NAND.

Learning objectives

  • Read NOR as inverted OR.
  • Identify the only input pair that produces 1.
  • Use NOR as an active-low any-input detector.

Circuit operation

The gate forms A + B and then complements the result. The output is 1 only when A = 0 and B = 0.

Verilog dataflow uses `assign y = ~(a | b);` or the primitive `nor (y, a, b)`. Like NAND, NOR is universal and can build any combinational function.

Inputs and outputs

A and B are active-high inputs and Y is the active-high output. NOR is an OR gate with an output bubble, so Y is the complement of A + B. It is not an OR gate with inverted inputs.

Practical example

  • Detecting the all-clear condition in an active-low fault system.
  • Building cross-coupled NOR SR latches.

Observations

  • NOR is the complement of OR, so exactly one row produces 1.
  • It is not an OR gate with inverted inputs; that different circuit is an AND gate.

Common mistakes

  • Mixing up NOR and NAND truth tables.
  • Assuming a NOR output is high when one input is low; both must be low.

Study this circuit 2 inputs · 1 output · 4 combinations · truth table and worked notes

Learning objectives

  • Relate the XOR symbol to inequality detection.
  • Predict the output for equal and unequal inputs.
  • Connect XOR to the sum output of an adder.

Circuit operation

The output is high when exactly one input is high. Equal inputs produce 0, whether both are 0 or both are 1.

Verilog writes this as `assign y = a ^ b;`. XOR is associative, so a chain of XOR gates computes the parity of all its inputs.

Inputs and outputs

A and B are active-high inputs. Y is high when exactly one input is high and low when the inputs match. The encircled plus sign is the XOR operator.

Practical example

  • Parity generation and error detection.
  • The sum bit of half and full adders.

Observations

  • XOR is not OR: 1 ⊕ 1 = 0 while 1 + 1 = 1.
  • The output detects difference, not the presence of a 1.

Common mistakes

  • Using OR when the equation calls for XOR.
  • Forgetting that an XOR chain inverts when an odd number of inputs is high.

Circuit operation

The output is high when A and B are both 0 or both 1. It is low when the inputs differ.

Inputs and outputs

Practical example

Observations

  • XNOR is the exact complement of XOR.
  • It produces 1 for two rows, not one.

Common mistakes

  • Calling XNOR "not OR"; it is not NOR.
  • Forgetting the output bubble when drawing the symbol.

2 inputs · 2 outputs · 4 combinations
logic 1 logic 0 active-high
Inputs
Outputs
S0
C0

Set the inputs to evaluate this circuit.

Boolean S = A ⊕ B C = A · B
Study this circuit 2 inputs · 2 outputs · 4 combinations · truth table and worked notes

Learning objectives

  • Derive sum and carry from the binary addition of two bits.
  • Explain why XOR gives the sum and AND gives the carry.
  • State why a half adder is insufficient for multi-bit addition.

Circuit operation

The sum output is A ⊕ B and the carry output is A · B. Adding 1 + 1 produces sum 0 and carry 1, which is binary 10.

The circuit is exactly one XOR gate and one AND gate sharing the same inputs. Verilog can describe it with two continuous assignments.

Inputs and outputs

A and B are the two active-high addend bits. S is the active-high sum bit and C is the active-high carry bit. The arithmetic value is 2·C + S, so 1 + 1 produces S = 0 and C = 1.

Practical example

  • The least significant stage of a small adder where no incoming carry exists.
  • A teaching block for separating sum and carry behaviour.

Observations

  • The arithmetic total is 2·C + S.
  • The half adder has no carry input, so it cannot be chained directly.

Common mistakes

  • Using OR for carry, which produces a carry for 0 + 1.
  • Trying to chain half adders without accounting for the missing carry input.

Full Adder

A full adder adds three one-bit inputs: A, B and the carry-in from the previous stage. It is the reusable stage of a ripple-carry adder.

3 inputs · 2 outputs · 8 combinations
logic 1 logic 0 active-high
Inputs
Outputs
S0
Cout0

Set the inputs to evaluate this circuit.

Boolean S = A ⊕ B ⊕ Cin Cout = A·B + Cin·(A ⊕ B)
Study this circuit 3 inputs · 2 outputs · 8 combinations · truth table and worked notes

Learning objectives

  • Compute sum and carry for all eight input combinations.
  • Use the propagate and generate terms to explain the carry.
  • Explain why a full adder can be chained.

Circuit operation

The sum is A ⊕ B ⊕ Cin. A carry is produced when A and B are both 1, or when exactly one of them is 1 and Cin is 1.

Using p = A ⊕ B and g = A · B, the carry is g + p·Cin. That form exposes why a carry can be generated locally or propagated from the previous bit.

Inputs and outputs

A, B and Cin are active-high one-bit inputs. S is the sum bit and Cout is the carry to the next stage. The arithmetic value is 2·Cout + S, covering totals from 0 to 3.

Practical example

  • Each bit slice of a ripple-carry, carry-select or carry-lookahead adder.
  • Arithmetic inside an ALU and address-generation units.

Observations

  • The full adder reduces to a half adder when Cin = 0.
  • With Cin = 1, the sum polarity of A ⊕ B is inverted and a carry can propagate.

Common mistakes

  • Leaving Cin out of the carry equation.
  • Using A + B for sum; sum is XOR, not OR.

Circuit operation

The difference is A ⊕ B. The borrow is ~A · B, because a borrow is needed only when A is 0 and B is 1.

The arithmetic result is difference minus 2·borrow. The half subtractor has no borrow input, so it cannot be chained without adding one.

Inputs and outputs

A is the active-high minuend bit and B is the active-high subtrahend bit. D is the difference and Bout is the borrow. Bout = 1 means the column needed to borrow 2 from the next stage.

Practical example

  • The least significant stage of a subtractor where no incoming borrow exists.

Observations

  • Difference uses XOR, the same as the half adder's sum.
  • Only 0 − 1 produces a borrow.

Common mistakes

  • Using A · ~B for borrow; that is the condition for no borrow.
  • Expecting a half subtractor to accept a borrow input.

Inputs

Boolean D = A ⊕ B ⊕ Bin Bout = ~A·B + Bin·~(A ⊕ B)
Study this circuit 3 inputs · 2 outputs · 8 combinations · truth table and worked notes

Learning objectives

  • Compute difference and borrow for all eight combinations.
  • Explain how an incoming borrow changes the operation.
  • Relate the full subtractor to a full adder.

Circuit operation

The difference is A ⊕ B ⊕ Bin. A borrow-out occurs when A is less than B + Bin.

Equivalently, Bout = ~A·B + Bin·~(A ⊕ B). The second term propagates a borrow when the difference of A and B would be zero before the incoming borrow is applied.

Inputs and outputs

A, B and Bin are active-high one-bit inputs. D is the difference and Bout is the borrow out. The result represents A − B − Bin, which can be negative even though D itself is a single bit.

Practical example

  • Each bit slice of a multi-bit subtractor.
  • Subtraction implemented as addition of a two's-complement value.

Observations

  • With Bin = 0 the circuit behaves as a half subtractor.
  • A borrow can be generated locally or propagated from the previous stage.

Common mistakes

  • Using ~A·B alone and forgetting the propagated borrow term.
  • Mixing the borrow input with the carry input of a full adder.

  • Distinguish unsigned carry-out from signed overflow.
  • Predict the result for boundary cases such as 15 + 1 and 8 + 8.

Circuit operation

The least significant full adder receives Cin. Its carry-out feeds the next stage, and so on. The four sum bits form S = A + B + Cin modulo 16.

Carry-out is the bit beyond bit 3. Overflow is different: it is set when two operands with the same sign produce a result with the opposite sign. Compare 15 + 1, which sets carry but not overflow, with 8 + 8, which sets both.

Inputs and outputs

A3…A0 and B3…B0 are the two active-high four-bit operands, with A3 and B3 the sign bits when the values are interpreted as signed. Cin is the carry into bit 0. S3…S0 is the four-bit sum, Cout is the carry beyond bit 3, and OVF is the signed overflow flag. Cout and OVF answer different questions.

Practical example

  • The arithmetic core of a small ALU or address incrementer.
  • A concrete example of carry propagation delay in a datapath.

Observations

  • The 512-row exhaustive table is verified by the engine test; the table below shows the boundary cases.
  • Unsigned carry and signed overflow answer different questions and can be set independently.

Common mistakes

  • Using carry-out as the overflow flag.
  • Reversing the bit order so A3 feeds the least significant stage.

Learning objectives

  • Explain how the select code chooses a data input.
  • Write the multiplexer expression as a sum of gated terms.
  • Verify that only the selected data bit reaches the output.

Circuit operation

The two select bits decode to one of four channels. The selected channel's data value appears at Y; the other channels are ignored.

The Boolean form is Y = ~S1·~S0·D0 + ~S1·S0·D1 + S1·~S0·D2 + S1·S0·D3. Only one product term is active for a given select code.

Inputs and outputs

D0…D3 are active-high data inputs. S1 and S0 form the active-high binary channel number, with S1 the high bit. Y follows the selected data input; the other data inputs have no effect on Y.

Practical example

  • Selecting one of several sensors, registers or buses for a shared data path.
  • Building a barrel shifter from a tree of multiplexers.

Observations

  • The select code chooses a channel; the data value itself does not affect which channel is chosen.
  • A 2:1 multiplexer needs one select line; a 4:1 needs two.

Common mistakes

  • Reversing S1 and S0, which swaps channels 1 and 2.
  • Confusing a multiplexer with a decoder; a decoder does not route data.

Circuit operation

The select code chooses one output. That output follows Din, while the other three are forced to 0. When Din = 0, all four outputs are 0 regardless of the select code.

This is a decoder with the data input acting as an enable. The one-hot property comes from the select decode; the data input gates the selected line.

Inputs and outputs

Din is the active-high data input and S1/S0 form the channel number. Exactly one output follows Din; the other three outputs are driven low. When Din = 0 every output is low, whatever the select code.

  • The unselected outputs are driven low, not left floating.

Learning objectives

Circuit operation

When EN = 1, the input code selects one output and drives it high. The other outputs stay low. When EN = 0, all four outputs are forced low.

Each output is a product term: Y0 = EN·~A1·~A0, Y1 = EN·~A1·A0, and so on. The enable makes the decoder safe to place on a shared bus.

Inputs and outputs

A priority encoder converts four request lines into a two-bit code, choosing the highest-numbered active request and reporting whether any request exists.

Boolean Valid = R3 + R2 + R1 + R0 Code1 = R3 + R2 Code0 = R3 + ~R2·R1
Study this circuit 4 inputs · 3 outputs · 16 combinations · truth table and worked notes

Learning objectives

  • Explain priority when more than one request is active.
  • Read the valid output as an any-request flag.
  • Write the encoder outputs as Boolean expressions.

Circuit operation

R3 has the highest priority, then R2, R1 and R0. The code reports the highest active request. If no request is active, valid = 0 and the code is 00.

The outputs are code1 = R3 + R2 and code0 = R3 + ~R2·R1. The valid flag is the OR of all requests. The code bits are not simply the two highest request lines because priority changes the encoding.

Inputs and outputs

R3…R0 are active-high request lines, with R3 highest priority. Code1 and Code0 report the highest active request. Valid is high when any request is active, which distinguishes request R0 from the no-request case.

Practical example

  • Interrupt controllers that must identify the highest-priority request.
  • Arbitration in a shared bus or memory port.

Observations

  • The output code can be 00 even when a request is active only if that request is R0; valid distinguishes this from the no-request case.
  • Multiple active inputs are allowed; the highest one wins.

Common mistakes

  • Ignoring priority and treating the input as one-hot only.
  • Forgetting the valid flag, which makes R0 and no-request indistinguishable.

Circuit operation

The comparator subtracts B from A internally and examines the result. In this demonstration the values are unsigned, so 1111 (15) is greater than 0000 (0).

Inputs and outputs

    Learning objectives

    • Distinguish a clock edge from a clock level.
    • Explain the roles of D, enable and asynchronous reset.
    • Predict Q after a sequence of load, hold and reset operations.

    Circuit operation

    Q changes only on a rising clock edge, and only when EN = 1. With EN = 0 the flip-flop holds its previous value even if D changes. Reset is asynchronous: asserting RST clears Q immediately, without waiting for a clock edge.

    The next-state equation is Qnext = RST ? 0 : (rising edge ? (EN ? D : Q) : Q). This is sequential behaviour: the output depends on the stored state as well as the current inputs. The clock button below produces one rising edge.

    Inputs and outputs

    D is the active-high data input. EN is an active-high enable and RST is an active-high asynchronous reset. Q is the stored state and Q̄ is its complement. The clock is an explicit control: only a rising edge can update Q.

    Practical example

    • Registers, pipelines and state machines.
    • Debouncing and synchronising a mechanical input to a clock domain.

    Observations

    • Changing D while the clock is not rising must not change Q.
    • Reset is asynchronous in this model, so it acts even with no clock edge.
    • Q̄ is always the complement of Q while Q is defined.
