Aim and scope

Implement a half subtractor and a full subtractor in Verilog-2001, then verify every difference and borrow output for all input combinations.

Subtraction is not merely addition with a different operator at the gate level. A subtractor needs a borrow path, and the direction of that borrow is the detail most often written backwards. This experiment isolates the borrow logic: the half subtractor subtracts two bits, the full subtractor also subtracts an incoming borrow and produces an outgoing borrow for the next more significant stage.

Both modules are combinational and use continuous assignments. The testbench computes the signed arithmetic difference independently and checks the two outputs against it, so a reversed borrow equation fails immediately.

Learning objectives

  • Derive the difference and borrow equations of a half subtractor.
  • Explain why the borrow is ~x & y and not x & ~y.
  • Build a full subtractor from two half subtractors and an OR gate.
  • Distinguish the incoming borrow bin from the outgoing borrow.
  • Verify all 4 half-subtractor and all 8 full-subtractor input combinations.
  • Interpret a negative arithmetic result alongside its two's-complement difference bit.

Theory and working principle

Subtracting one bit from another gives a difference bit and a borrow bit. The four cases are:

  • 0 − 0 = 0 with no borrow.
  • 1 − 0 = 1 with no borrow.
  • 1 − 1 = 0 with no borrow.
  • 0 − 1 cannot be represented in one unsigned bit, so the result is 1 with a borrow of 1. Read as a two-bit value, the answer is 10, which is 2; in signed arithmetic the difference is −1.

The difference column is 1 when the inputs differ, so diff = x ^ y. The borrow column is 1 only in the last case, where x is 0 and y is 1, so borrow = ~x & y. The negation applies to x alone; parentheses are unnecessary here because unary NOT binds tighter than AND.

A full subtractor computes x − y − bin. It can be decomposed into two half subtractions: first x − y produces an intermediate difference d and borrow b1; then d − bin produces the final difference and borrow b2. The stage borrows out if either half subtraction borrowed, so borrow = b1 | b2. The final difference is diff = d ^ bin.

This decomposition is exactly what the design writes out: d = x ^ y, b1 = ~x & y, b2 = ~d & bin, diff = d ^ bin and borrow = b1 | b2.

Line-by-line explanation

Design

  • half_subtractor declares x, y, diff and borrow. Both outputs are wires driven continuously.
  • assign diff = x ^ y; makes the difference 1 when the operands differ.
  • assign borrow = ~x & y; asserts borrow only for x = 0, y = 1. The NOT applies to x before the AND.
  • full_subtractor declares the incoming borrow bin and three internal wires.
  • assign d = x ^ y; and assign b1 = ~x & y; are the first half subtraction.
  • assign b2 = ~d & bin; is the borrow produced when the incoming borrow is larger than the intermediate difference.
  • assign diff = d ^ bin; subtracts the incoming borrow from d.
  • assign borrow = b1 | b2; combines the two borrow sources. This is the OR block in the diagram.

Testbench

  • expected_value is an integer, so a negative difference is retained rather than wrapped into an unsigned bit.
  • expected_value = hs_x; expected_value = expected_value - hs_y; performs the subtraction in two statements. Splitting the expression avoids one-bit expression truncation before the value reaches the integer.
  • expected_borrow = (expected_value < 0); derives the borrow from the arithmetic sign.
  • {expected_borrow[0], expected_value[0]} builds the two-bit expected result. For −1, expected_value[0] is 1 and the borrow is 1, giving 11.
  • if ({hs_borrow, hs_diff} !== ...) compares the concatenated outputs in one operation.
  • The full-subtractor loop uses three statements for the same reason and covers 000 through 111.
  • $display prints the signed arithmetic value, so a row such as 0 1 1 shows −2 next to diff = 0, borrow = 1.

Waveform and timing

The circuit is combinational, so there is no clock edge to align with. Each vector is held for 1 ns: the half subtractor occupies 0–4 ns and the full subtractor occupies 4–12 ns. The simulator's finish message at 12,000 ps means 12 ns.

A waveform would show borrow rising whenever the arithmetic result goes negative. Because the model is zero-delay, the output changes in the same time step as the input; the #1 gives the testbench a stable point at which to sample.

Result

Both subtractors matched the signed arithmetic model.

All 12 input combinations — 4 half-subtractor and 8 full-subtractor vectors — produced 0 mismatches. Every borrow bit agrees with the sign of the difference, and every difference bit agrees with the low bit of the result.

This exhausts the input space of both circuits. It verifies the borrow direction as well as the difference, which is the part a casual reading of the code often gets wrong.

Common mistakes and troubleshooting

Reversing the borrow

borrow = x & ~y asserts borrow when x = 1, y = 0, the opposite of the required case. The correct half-subtractor borrow is ~x & y.

Dropping the second borrow

A full subtractor that uses only b1 fails whenever bin causes the borrow. Both b1 and b2 must reach the OR.

Confusing bin with borrow

bin is an input from the less significant stage; borrow is this stage's output. Wiring them to the same name silently breaks a multi-bit subtractor.

Subtracting in one-bit expressions

x - y with one-bit operands wraps before it reaches an integer. Subtract step by step into an integer when computing an expected value.

Using OR instead of XOR for the difference

OR is 1 for 1 − 1, but the difference is 0 there. Difference is XOR.

Assuming borrow means a negative number

Borrow is a positional signal. In a wider subtractor the final borrow can indicate underflow, but an intermediate borrow is normal and is resolved by the next stage.

Revision points

  • Half subtractor: diff = x ^ y, borrow = ~x & y.
  • Full subtractor: diff = x ^ y ^ bin, with borrow from either half subtraction.
  • Two half subtractors plus an OR make a full subtractor.
  • The direction of the borrow inequality is the critical detail: borrow when y > x.
  • Four and eight vectors exhaust the two-input and three-input truth tables.
  • A negative signed result always pairs with an outgoing borrow of 1.
