What is verified

The PC workflow is tested. The phone is for study.

The Windows guide uses the installed, verified toolchain: Icarus Verilog 13.0, the matching vvp runtime, GTKWave 3.3.128 and Python 3.14.7. The Android guide covers the static site, local progress, the Playground editor and downloads. It does not claim that Android runs Icarus.
