Details and tables

What does non-blocking mean?
The right-hand side is evaluated, then the assignment is scheduled for the end of the current time step. It models sequential hardware more safely than blocking assignment in clocked always blocks.
Why use a testbench?
A testbench applies stimuli, observes outputs and makes a design verifiable before synthesis.

04 / Accessibility

Non-negotiables

These checks apply to every page, component and interactive circuit before release.

Keyboard

Every interactive element is reachable with Tab, operable with Enter or Space, and has a visible focus state.

Contrast

Body and muted text are checked against their surfaces in both themes. Colour is never the only carrier of state.

Touch

Mobile controls meet a 44px target. Code blocks scroll horizontally; tables remain contained.

Motion

Reduced-motion preferences remove ambient animation and reveal transitions while preserving content.

05 / Implementation

Architecture notes

The site is static, modular and dependency-free at runtime. The build step only assembles shared shells and content fragments.

CSS

Seven layers: fonts, tokens, themes, base, layout, components and pages. Components consume tokens only; themes override values.

css/tokens.css

JavaScript

Native ES modules. Theme, navigation, copy, dialogs, toasts, reveal and motion controls are isolated in ui.js.

js/ui.js

Build

A standard-library Python script wraps content fragments in the shared shell and resolves relative paths for GitHub Pages subpaths.

tools/build.py

Performance

No framework, no external requests, local fonts, CSS gradients and inline SVG. Animations are limited to transform and opacity.
