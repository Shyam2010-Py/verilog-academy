Android · Chrome

Written for Chrome on Android 10 or newer. Other browsers follow the same layout but may word downloads differently.

Evidence note: the phone layout was verified in Chrome device emulation at 360–412 px. This release was not exercised on a physical Android handset.

01 / Quick start

Five minutes on a phone.

  1. Open the Academy from a local preview server or a hosted copy. Do not open the HTML files directly from a file manager if you need JavaScript features.
  2. Tap the menu button to reach Theory, Laboratory, Circuit Lab, Playground and Dashboard.
  3. Read a topic and tick its completion box at the end. Progress is stored in this browser.
  4. Try the Circuit Lab by tapping the input switches and watching the outputs and truth table update.
  5. Open the Playground to edit a project, copy it or download design.v and tb.v for a PC.

No install is required on the phone. The Academy is a static site. There is no Android app to download, no account to create and no cloud sync to enable.

03 / Open the site

Use a server, not a file path.

The Academy is built from static files, but it uses JavaScript modules for the theme, dashboard, quizzes and Playground. Chrome blocks module imports from file:// URLs for security reasons, so opening index.html directly from a phone file manager can leave those features inactive.

Option A

Preview from a PC over Wi-Fi

Run the project's preview server on the Windows machine, find its local address and open it in the phone browser on the same network.

C:\msys64\ucrt64\bin\python.exe tools\serve.py

The server prints a local URL. Use the PC's LAN address if localhost is not reachable from the phone.

Option B

A hosted copy

When the owner publishes the site, open its HTTPS address in Chrome. The hosted copy behaves like any static website and needs no local server.

This guide does not claim that a public deployment exists. Ask the owner for the current address.

Do not judge the site from a file-manager preview. If the menu button, theme toggle or quizzes do nothing, the page was probably opened through file://. Serve it over HTTP and reload.

04 / Navigation

The same site, rearranged for a thumb.

At phone widths the desktop navigation is replaced by a menu button in the header. Tapping it opens a full-screen navigation dialog with large links and a close button.

  • Header: the logo returns to the homepage; the moon/sun button switches between Midnight and Daylight.
  • Menu: Theory, Laboratory, Circuit Lab, Playground, Quizzes, Guides and Dashboard are one tap away.
  • Back: the Android back gesture closes the menu dialog first, then follows the browser history.
  • Anchors: in-page links such as “Choose a bank” scroll smoothly unless reduced motion is enabled.
  • Footer: every page repeats the curriculum, platform and setup-guide links.

Accessibility is not desktop-only. Focus outlines, skip links, labelled controls and reduced-motion support remain active on a phone. Text can be enlarged with the browser's font-size setting.

05 / Study

Read, copy, and mark a topic complete.

Theory and laboratory pages use a single-column reading layout on a phone. The table of contents, code blocks and pager cards stack vertically, and wide tables scroll inside their own container instead of forcing the page sideways.

Reading

What to expect

Section numbers, a reading-time estimate, code blocks with copy buttons and a previous/next pager at the end.

Progress

The completion control

Each topic and available experiment has a checkbox. Ticking it writes to va.progress in this browser and updates the dashboard.

Completion is a local record, not a grade. A quiz attempt never ticks a lesson or experiment; the two systems are deliberately separate.

Copying code on Android. Tap the copy button on a code block, then paste into any note or editor. If the browser blocks clipboard access, long-press the code and select it manually.

06 / Circuit Lab

Tap an input. Watch the logic answer.

The Circuit Lab is built for touch as well as pointer input. Choose one of the 18 demonstrations, then tap the input switches to toggle them between 0 and 1.

  1. Pick a circuit from the demonstration library — gates, adders, subtractors, multiplexers, encoders, decoders, a comparator or the clocked D flip-flop.
  2. Toggle inputs and read the output badges and Boolean equation.
  3. Check the truth table to see the full behaviour, not just the current row.
  4. Use Reset to return the circuit to its starting state before trying another pattern.

Ideal logic, not timing. The lab evaluates Boolean values immediately. It does not model gate delays, rise times or setup/hold violations, so a correct lamp pattern is not a timing sign-off.

07 / Playground

Edit on the phone. Compile on the PC.

The Playground works well on a phone for reading, small edits, copying and downloading. The editor uses a monospaced text area with a line-number gutter, horizontal scrolling for long lines, and a Tab key that inserts two spaces.

Playground controls on Android
ControlWhat it does
Design / Testbench tabsSwitches between design.v and tb.v without losing either edit.
CopyCopies the active file to the clipboard.
Download design.vDownloads the current design text as a .v file.
Download tb.vDownloads the current testbench text as a .v file.

Edits are saved as drafts under va.playground.drafts after a short pause. Drafts never mark a lesson complete and never change va.progress. Once either file changes, the reference transcript is labelled as belonging to the original example only; nothing is recompiled until you run Icarus locally.

Downloads are files, not runs. Android saves the .v files to Downloads. It does not open, compile or simulate them. Transfer both files to the Windows machine for the compile step.

08 / Quizzes

Four banks, one question at a time.

The quiz page uses a single-question layout on a phone. The question palette becomes a horizontally scrollable strip above the Previous and Next buttons, so a twelve-question bank still fits without shrinking the text.

  1. Choose a bank: EC-405 Theory, EC-410 Laboratory, Circuit Lab or Playground Fundamentals.
  2. Select one option per question. Answers can be changed until you submit.
  3. Submit to see the score. Unanswered questions are marked incorrect after a confirmation step.
  4. Review the explanation for every question, then retry or open a saved attempt from the history panel.

Quiz attempts are stored separately under va.quizzes. They do not unlock Units 4–5, mark Experiments 7–15 available, or change lesson completion.

09 / Progress and backups

Everything local. Nothing silently synced.

The Academy keeps four independent browser keys. Understanding them makes backups and troubleshooting much easier.

Browser storage keys used by the Academy
KeyStoresWritten by
va.progressCompleted topics and experiments, plus activity timestamps.Lesson and laboratory completion controls.
va.quizzesQuiz attempt history, answers and scores.The quiz page.
va.playground.draftsUnsaved-to-disk editor text for Playground projects.The Playground editor.
va.themeMidnight or Daylight preference.The header theme toggle.

To protect progress, open the dashboard and use Export JSON. The backup contains the validated progress record. Import backup checks the file before replacing anything; malformed or unsupported files are rejected rather than half-applied.

Clearing site data erases local records. “Clear browsing data”, private/incognito mode, or a browser cleanup tool can remove all four keys. Export a backup first if the progress matters.

10 / Compilation limits

Why the phone cannot run the simulator.

The Academy is HTML, CSS, JavaScript and JSON. It has no server-side compiler, no WebAssembly Verilog engine and no bundled simulator. A phone browser therefore cannot turn design.v into a running simulation by itself.

Not available

Icarus on Android

Icarus Verilog is installed here as a Windows UCRT64 program. This release does not ship an Android build and does not document an unverified Termux installation.

Not available

Waveform viewing

No VCD viewer is bundled. GTKWave runs on the Windows desktop; the phone can store a VCD but not display it in this release.

The honest workflow

Edit here, compile there

Use the phone for reading and small edits. Download the files, transfer them to the PC, and follow the verified Windows compile and run commands.

If a future release adds a tested Android toolchain, it will be documented with the same evidence standard as the Windows guide: exact version, exact command and a real transcript.

11 / Troubleshooting

Phone-specific problems, plain fixes.

Common Android issues
SymptomLikely causeFix
Menu button or theme toggle does nothingThe page was opened through file://, so modules did not load.Serve the site over HTTP from the PC or use the hosted copy, then reload.
Downloaded file is named .txtThe browser or file manager changed the extension.Rename it to design.v or tb.v before compiling on the PC.
Download does not appearChrome saved it silently or the notification was dismissed.Open Chrome's Downloads, or check the device's Download folder.
Keyboard covers the editorThe on-screen keyboard reduces the visible viewport.Scroll the editor into view; rotate to landscape for more width.
Progress disappearedSite data was cleared, or the page is open in private mode.Use a normal tab, avoid clearing site data, and import a dashboard backup if you have one.
Old page still appears after an updateThe browser cached the previous files.Reload with cache bypass, or clear the site's cached data. Progress keys are separate from the cache.
Quiz history is emptyNo attempt has been submitted for that bank, or storage is blocked.Submit one attempt in a normal tab. A storage warning toast means the browser refused to save.
Wide table pushes the page sidewaysA table wider than the viewport.Scroll the table itself horizontally; the page layout is designed to contain it.
