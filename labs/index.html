01 / The bench

Six circuits. Six verified transcripts.

Each experiment is a complete bench record: aim, theory, diagram, equations, truth table, design, testbench, commands, actual output and viva preparation. Work through them in order, or open any experiment whose circuit you already understand.

Laboratory objectives

What these six experiments build

  • Derive a truth table and Boolean equations before writing any Verilog.
  • Implement combinational circuits in Verilog-2001 using gate primitives, dataflow assignments and always @*.
  • Write a self-checking testbench that drives every required input combination.
  • Compile with iverilog -g2001 and run the simulation image with vvp.
  • Compare the simulator transcript against the expected truth table and explain every column.
  • Diagnose mismatches, undriven outputs, inferred latches and reversed bus order.

02 / The method

Write it. Compile it. Compare it.

A laboratory result is not a screenshot of code. It is a design, a stimulus, a simulator transcript and a comparison against the expected behaviour. Every experiment here follows the same four steps.

  1. DeriveWrite the Boolean behaviour or the structural connection before writing Verilog.
  2. DescribeImplement the circuit in Verilog-2001 and keep the module ports aligned with the diagram.
  3. StimulateDrive every required input combination from a testbench, not by hand-editing values.
  4. CompareRead the transcript against the truth table and record the mismatch count.
Exact workflow · Experiment 01

Compile and run from the example directory

Terminal 
iverilog -g2001 -o experiment-01.out design.v tb.v
vvp experiment-01.out

The build uses -g2001, so the source is checked against Verilog-2001 rather than a newer language mode. The .out file is an Icarus simulation image, not a hardware bitstream.

03 / Required tools

A small, free toolchain.

No online simulator and no account are required. The laboratory needs a text editor, a terminal, and Icarus Verilog. Waveform viewing is optional because every experiment records its result as text.

Icarus Verilog 13.0

The compiler iverilog checks and elaborates the design; vvp runs the resulting simulation image. Every transcript on this site was produced with this toolchain in Verilog-2001 (-g2001) mode.

Required · installed and used for verification

Text editor

Any editor that saves plain UTF-8 text works. Keep design.v and tb.v in the same working directory so the command lines in each experiment apply without changes.

Required · no plugin or extension

Terminal

PowerShell, Command Prompt, Bash or any shell that can find iverilog and vvp. If the commands are not on PATH, call them with their full install path.

Required · same directory as the sources

GTKWave (optional)

The experiments use $display transcripts, so a waveform viewer is not needed to complete them. If you add $dumpfile and $dumpvars, GTKWave is a convenient way to inspect the result.

Optional · not required by any experiment
Version honesty.

The commands use Verilog-2001 syntax. A different simulator may accept the same files and print a different transcript layout; compare the values, not the spacing. The outputs shown on each experiment page are the actual Icarus 13.0 outputs captured for this release.
