Unit 0120 periods · 10 topics

Introduction to Verilog HDL, Language Constructs and Conventions

The language and its rules. Before a single gate is described, you need the design flow, the vocabulary of HDL-based design, the module as a unit of hierarchy, and the data model that every later construction depends on.

Learning objectives

  • Trace a design from specification to silicon and identify where Verilog enters the flow.
  • Compare Verilog with VHDL and place each modelling style on the abstraction ladder.
  • Build and connect module hierarchies with correct port directions and widths.
  • Use literals, nets, variables, vectors, arrays, parameters and system tasks correctly.
  • Evaluate expressions with Verilog's width, signedness and precedence rules.

Unit 0210 periods · 6 topics

Gate Level and Data Flow Modelling

Structural and dataflow modelling. Describe hardware as a netlist of primitive gates or as continuous equations over signals, then assemble the arithmetic and routing blocks that make up a datapath.

Learning objectives

  • Instantiate gate primitives and model rise, fall and turn-off delays.
  • Write continuous assignments that describe combinational hardware without inferred storage.
  • Build adders, subtractors, comparators, multiplexers, decoders and encoders.
  • Choose between gate-level, dataflow and behavioural descriptions for a given block.

Unit 0315 periods · 7 topics

Behavioural Modelling

Behavioural modelling. Procedural blocks describe what hardware does over time. This unit covers the event model, assignment scheduling, timing controls, decision constructs, loops, block structure and custom primitives.

Learning objectives

  • Distinguish initial from always, and blocking from non-blocking assignments.
  • Use delay, event and wait controls, and know which controls synthesis ignores.
  • Write conditionals, case statements and loops that synthesise predictably.
  • Explain sequential and parallel blocks, and define combinational and sequential UDPs.
